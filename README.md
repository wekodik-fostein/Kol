# Kol

3D-шутер от первого лица на Godot 4.3 для Android.

- **Против ботов** — офлайн, 4 бота.
- **LAN-сервер** — один телефон/ПК жмёт «Создать», остальные в той же Wi-Fi вводят его IP и жмут «Подключиться». Порт `7777`.
- **Управление на телефоне** — левая половина экрана: ходьба, правая: обзор, кнопки FIRE и JUMP справа внизу.
- **На ПК для теста** — WASD, мышь, пробел (прыжок), ЛКМ или F (огонь), Esc — отпустить мышь.

## Сборка APK

Каждый push в `main` запускает GitHub Actions (`.github/workflows/build-apk.yml`).
Готовый APK лежит в артефакте `Kol-debug-apk` на вкладке Actions.

Локально: открыть проект в Godot 4.3, Project → Export → Android → Export Project.

## Важно

- Текстуры из Google Drive не подключены: папка по ссылке закрыта для скачивания. Нужно выложить файлы в `assets/` и подключить их к материалам.
- Урон от попаданий считает сам клиент, а хост только проверяет лимит. Для LAN-игры с друзьями ок, для честного онлайна — нет.
- Модели GLB лежат в `assets/` (`soldier.glb`, `map.glb`).
